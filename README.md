# Budget App: Ansible Deployment

Cloud IA project by Shreyasi Bidkar.

Ansible inventory and playbooks used to deploy the Budget App
(Spring Boot backend, React frontend, MySQL database).

- `inventory.ini`, `playbook.yml`: deployment to an AWS EC2 instance
- `inventory-local.ini`, `playbook-local.yml`: deployment on local WSL

Application source: https://github.com/xunhongt/bob-budget-app
